# Changelog

## F1-22 R2 — checkpoint языкового шаблона

Добавлен транспортный codec и стык сохранения в `source/sales_template_checkpoint.py`.

- `capture_checkpoint` проверяет безопасный domain, один раз вызывает принятый F122 и возвращает канонический blob.
- `materialize_checkpoint` проверяет формат, размер, JSON, схему, каноничность и digest, затем заново вызывает F122 и сверяет версии registry/pack.
- `prepare_checkpoint_materials` пропускает текущие аргументы в принятый F130 и только после его проверок сравнивает checkpoint с текущими materials. Внешний save вызывается один раз и только при полном совпадении.

Принятый `materialize_bound_template` и остальные зависимости не изменялись. Добавлены собственные тесты, документация и журнал фактических прогонов.

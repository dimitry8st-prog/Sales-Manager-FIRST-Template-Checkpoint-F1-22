# Сдача

Верните F1-22_R2_RETURN_R1.zip с одним корнем, полным исходным пакетом и разрешёнными изменениями. Не кладите venv/cache/__pycache__/секреты/дампы. CHECK_PACKAGE.py и frozen inputs/source dependencies сохраняются.

Обязательно: реализация; собственные исполняемые unittest tests; TRACEABILITY.md (требование→код→тест); CHANGELOG.md; LIMITATIONS.md; docs/IMPLEMENTATION.md со стыками и откатом; evidence/commands.json, stdout/stderr и exitcode baseline/candidate/owntests; RETURN_MANIFEST.json sha256 всех файлов кроме себя. Не придумывать PASS: отсутствие проверки обозначать NOT_RUN с причиной. Baseline PASS не является приёмкой компонента. Собственные tests обязаны обнаруживаться, иметь ненулевой count и ноль skips. Содержательные negative/metamorphic/boundary tests обязательны, не только копия public tests.

Критерии: EN/RU пять видов плюс synthetic third locale; exact text/whitespace/fact ordering; canonical equality при перестановке dict keys; bytes/duplicate keys/UTF8/surrogate/cycle/depth/limit/types/subclasses/extras; schema/hash/canonical приоритет; rehashed semantic invalidity; registry/pack pin mismatch; фактический F122 при capture/decode; фактическая цепь F130→F120→F122→consumer при bridge; текущая истёкшая привязка перед broken blob; same-version changed literal text → mismatch; другое id с тем же text → mismatch; callback return identity/error identity; zero callback на всех отказах; immutability; отсутствие I/O. Граница byte limit проверить с валидным large text в обоих loaded/bound, а не ломать семантику acceptedcore. Checkpoint не доказывает trust и не должен добавлять разрешения.
